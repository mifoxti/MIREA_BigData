# 🎓 MIREA BigData - Практические работы по дисциплине "Технологии и инструментарий анализа больших данных" (ТИАБД)

Добро пожаловать в репозиторий с практическими работами по курсу **ТИАБД** в **МИРЭА**! 🚀

## 📚 Описание

Этот репозиторий содержит решения практических заданий по курсу "Технологии и инструментарий анализа больших данных". Каждая папка соответствует номеру практической работы и включает в себя код, данные и результаты анализа.

## 📁 Структура репозитория

### Практические работы
- **first_prac/** - Практическая работа №1: Основы Python и Jupyter
  - Базовые алгоритмы и структуры данных
  - Работа с файлами и строками
  - Основы машинного обучения с sklearn

- **second_prac/** - Практическая работа №2: Визуализация данных
  - Анализ датасетов
  - Создание графиков и диаграмм
  - Использование matplotlib, seaborn, t-SNE, UMAP

- **third_prac/** - Практическая работа №3: Статистический анализ
  - Работа с различными датасетами (BMI, COVID-19, страховки)
  - Статистические тесты и анализ

- **fourth_prac/** - Практическая работа №4: Линейная регрессия
  - Анализ данных о недвижимости Москвы
  - Построение моделей регрессии

- **fifth_prac/** - Практическая работа №5: Классификация
  - Обработка данных Steam
  - Сравнение моделей: KNN, SVM, Logistic Regression
  - Балансировка классов и оценка моделей

- **sixth_prac/** - Практическая работа №6: Продвинутые методы
  - Анализ данных Steam с дополнительными признаками
  - Различные алгоритмы машинного обучения

- **seventh_prac/** - Практическая работа №7: Ансамблевые методы
  - Bagging (Random Forest) и Boosting (XGBoost)
  - Сравнение моделей и визуализация результатов
  - Важность признаков, зависимость точности от параметров

## 🚀 Запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/mifoxti/MIREA_BigData.git
   cd MIREA_BigData
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   # или
   source .venv/bin/activate  # Linux/Mac
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Если файла requirements.txt нет, установите необходимые пакеты вручную)*

4. **Запустите нужную практическую работу:**
   ```bash
   cd seventh_prac
   python task1.py
   ```

## 📊 Результаты

### Последняя практическая работа (№7)
В седьмой практике реализованы ансамблевые методы машинного обучения:
- **Random Forest (Bagging)** 🌲
- **XGBoost (Boosting)** ⚡

#### Визуализации:
- Важность признаков
- Зависимость точности от количества деревьев
- Время обучения от количества деревьев

#### Сравнение моделей:
- Random Forest: более интерпретируемый, устойчивый к переобучению
- XGBoost: обычно выше точность, но дольше обучается
